# Repository Working Rules

## Git workflow

- Work on the currently checked-out branch. Do not create or switch branches unless the user explicitly requests it.
- Write commit subjects as brief, imperative statements describing what the commit does. Avoid phase labels, broad summaries, and conventional-type prefixes unless the user requests them.
- For substantial commits, use a body containing exactly four concise bullet points that collectively summarize the complete change being pushed.
- Do not add co-author trailers or references to assistants, models, automated generation, or development tools in commit messages.
